## 👨‍💻 About me

I build software across the whole stack — from native C++ extensions and ML inference to production APIs and
infrastructure. Right now, I'm working on [Vintoria](https://vintoria.ru/), an app that recognizes wine labels,
organizes collections, and provides personalized recommendations.

- 🧠 Applied ML, computer vision, vector search, and ONNX inference
- ⚙️ Async Python backends, databases, queues, observability, and containers
- 📱 Cross-platform tooling for desktop, Android, and iOS
- 🤝 **48 merged pull requests** in projects outside my own repositories
